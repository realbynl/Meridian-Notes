> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ctrl+K "Quiz this note / Quiz selection / Quiz all notes": a shuffled, scored, self-graded run over cloze cards plus auto-hidden headings and list items, with no schedule or log writes.

**Architecture:** A pure `quiz.rs` (question builder, seeded shuffle, session, score) beside `cards.rs`, and `app/quizui.rs` (collect notes read-only, key handling, drawing) beside `app/cardsui.rs`. The card panel drawing in `draw_cards` is extracted into a shared helper so both overlays look alike.

**Tech Stack:** Rust, crate `onyx` (`crates/onyx/src`), ratatui-free custom `screen`, unit tests in-file, tmux for manual checks.

**Spec:** `docs/superpowers/specs/2026-10-07-quiz-mode-design.md` (also read `docs/superpowers/specs/2026-10-06-study-cards-design.md` for the card format).

**Not a git repo:** there are no commit steps. Run everything from the project root `/mnt/C/Dropbox/Dropbox/+Projects/Coding/Bash/the legacy editor`. Baseline: `cargo test -p onyx` = 480 passed.

## Global Constraints

- A quiz never reads or writes `<config>/cards/*.cards`, `review.log`, `index`, or the today counter, and never registers notes (so it must NOT call `cards_collect`, `cards_register`, `cards_save`, or `cards_new_used`).
- Nothing is written to the note; no syntax to learn; entries only through Ctrl+K, the right-click menu and the command palette.
- Keys: Space/Enter/click reveal, `y` got it, `n` missed, `Esc`/`q` end; result screen `r`, `s`, Up/Down, Enter/Esc.
- A missed question is re-queued once; score counts first attempts only.
- Notes larger than `MAX_NOTE` (2 MiB) are skipped; only `md`, `markdown`, `txt` files are quizzed in "all notes".
- Quizzing is allowed on read-only buffers.
- Messages: "nothing to quiz: select a heading or list", "save the note first", "select some text first", "the note is gone".

## Review Focus

- Heading or list-looking lines inside fenced code (```` ``` ````/`~~~`) must not become questions (test in Task 1).
- CRLF notes: the hidden body must not carry stray `\r` (test in Task 1).
- Nested headings: a `##` body runs through its `###` children and stops at the next `##` or `#` (test in Task 1).
- A selection that ends at column 0 of the next line must not pull that line in (test in Task 1, `selected_lines`).
- A very long section (top-level heading over a whole note) must clip, not crash or overflow the panel (tmux check, Task 3).
- Esc before answering anything closes silently; after one answer it shows the result; a buffer with no path can still quiz a selection and jump back to its line (tmux check, Task 3).

impl Question {
    /// First line of the question text, for the result list.
    pub fn label(&self) -> String {
        let all: String = self.segs.iter().map(|(t, _)| t.as_str()).collect();
        all.lines().next().unwrap_or("").chars().take(50).collect()
    }
}

fn line_at(ls: &[(usize, usize, String)], at: usize) -> usize {
    ls.iter().position(|(s, e, _)| at >= *s && at <= *e).unwrap_or(ls.len() - 1)
}

/// Per line: inside or on a ``` / ~~~ fence.
fn code_lines(ls: &[(usize, usize, String)]) -> Vec<bool> {
    let mut open = false;
    ls.iter()
        .map(|(_, _, t)| {
            let t = t.trim_start();
            if t.starts_with("```") || t.starts_with("~~~") {
                open = !open;
                true
            } else {
                open
            }
        })
        .collect()
}

fn title(line: &str, level: usize) -> String {
    line.trim_start().chars().skip(level + 1).collect::<String>().trim().to_string()
}

/// Every question in a note, by source line: its cloze cards, the body of each heading, and each
/// list item under a heading. Regions holding a cloze are covered by the card, not asked twice.
/// `lines` keeps only questions whose source line is in that inclusive 0-based range.
pub fn questions(path: &Path, text: &str, lines: Option<(usize, usize)>) -> Vec<Question> {
    let ls = cards::lines_of(text);
    let code = code_lines(&ls);
    let mut cloze = vec![false; ls.len()];
    for z in cards::parse(text) {
        for l in line_at(&ls, z.start)..=line_at(&ls, z.end.saturating_sub(1).max(z.start)) {
            cloze[l] = true;
        }
    }
    let mk = |line: usize, heading: Option<String>, segs: Vec<(String, bool)>| Question { path: path.to_path_buf(), line, heading, segs };
    let mut out: Vec<Question> = cards::cards_in("", text).into_iter().map(|c| mk(c.line, c.heading, c.segs)).collect();
    let mut heading: Option<String> = None;
    for i in 0..ls.len() {
        if code[i] {
            continue;
        }
        let t = &ls[i].2;
        if let Some(n) = cards::heading_level(t) {
            let name = title(t, n);
            let mut j = i + 1;
            while j < ls.len() && !(!code[j] && cards::heading_level(&ls[j].2).is_some_and(|m| m <= n)) {
                j += 1;
            }
            let body = ls[i + 1..j].iter().map(|l| l.2.as_str()).collect::<Vec<_>>().join("\n");
            let body = body.trim();
            if !cloze[i] && !body.is_empty() && !cloze[i + 1..j].iter().any(|&c| c) {
                out.push(mk(i, None, vec![(name.clone(), false), ("\n".into(), false), (body.to_string(), true)]));
            }
            heading = Some(name);
        } else if let (Some(off), Some(_), false) = (cards::list_text_offset(t), &heading, cloze[i]) {
            let chars: Vec<char> = t.chars().collect();
            let item: String = chars[off.min(chars.len())..].iter().collect();
            let item = item.trim();
            if !item.is_empty() {
                out.push(mk(i, heading.clone(), vec![(chars[..off].iter().collect(), false), (item.to_string(), true)]));
            }
        }
    }
    if let Some((a, b)) = lines {
        out.retain(|q| q.line >= a && q.line <= b);
    }
    out.sort_by_key(|q| q.line);
    out
}

/// The 0-based inclusive line range a selection of char offsets covers; a selection ending at
/// column 0 of a line does not include that line.
pub fn selected_lines(text: &str, start: usize, end: usize) -> (usize, usize) {
    let ls = cards::lines_of(text);
    let (a, mut b) = (line_at(&ls, start), line_at(&ls, end));
    if end > start && b > a && end == ls[b].0 {
        b -= 1;
    }
    (a, b)
}

/// Fisher-Yates with an xorshift generator; the same seed gives the same order.
pub fn shuffle<T>(v: &mut [T], mut seed: u64) {
    seed |= 1;
    for i in (1..v.len()).rev() {
        seed ^= seed << 13;
        seed ^= seed >> 7;
        seed ^= seed << 17;
        v.swap(i, (seed % (i as u64 + 1)) as usize);
    }
}

/// A quiz run: the queue (each question with whether it is a second attempt) and the score.
pub struct Session {
    queue: VecDeque<(Question, bool)>,
    pub revealed: bool,
    pub total: usize,
    pub answered: usize,
    pub correct: usize,
    pub missed: Vec<Question>,
}

impl Session {
    pub fn new(mut qs: Vec<Question>, seed: u64) -> Session {
        shuffle(&mut qs, seed);
        Session { total: qs.len(), queue: qs.into_iter().map(|q| (q, false)).collect(), revealed: false, answered: 0, correct: 0, missed: Vec::new() }
    }

    pub fn current(&self) -> Option<&Question> {
        self.queue.front().map(|(q, _)| q)
    }

    pub fn reveal(&mut self) {
        self.revealed = true;
    }

    /// Self-grade the current question. A first-attempt miss is asked once more at the end; second
    /// attempts do not count.
    pub fn answer(&mut self, got: bool) {
        let Some((q, retry)) = self.queue.pop_front() else { return };
        self.revealed = false;
        if retry {
            return;
        }
        self.answered += 1;
        if got {
            self.correct += 1;
        } else {
            self.missed.push(q.clone());
            self.queue.push_back((q, true));
        }
    }

    pub fn finished(&self) -> bool {
        self.queue.is_empty()
    }

    pub fn percent(&self) -> u32 {
        if self.answered == 0 { 0 } else { (self.correct * 100 / self.answered) as u32 }
    }
}

//! Quiz mode on `App`: collect questions (read-only), run the quiz, show the score. Never writes
//! card schedules, the review log or the cards index.

use super::cardsui::{is_note, MAX_NOTE};
use super::*;
use crate::commands::QuizOp;
use crate::quiz;

pub(super) struct QuizUi {
    pub s: quiz::Session,
    pub scope: String,
    /// Showing the score instead of a question.
    pub result: bool,
    /// Highlighted row of the missed list.
    pub sel: usize,
}

fn seed() -> u64 {
    std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).map_or(1, |d| d.as_nanos() as u64)
}

impl App {
    pub(super) fn quiz_cmd(&mut self, op: QuizOp) {
        let text = self.buf.rope().to_string();
        let here = self.buf.path().map(Path::to_path_buf);
        let (qs, scope) = match op {
            QuizOp::Note => match &here {
                Some(p) => (quiz::questions(p, &text, None), p.file_name().map_or(String::new(), |n| n.to_string_lossy().into_owned())),
                None => return self.notify("save the note first", true),
            },
            QuizOp::Selection => {
                let r = self.buf.primary();
                if r.is_empty() {
                    return self.notify("select some text first", true);
                }
                let lines = quiz::selected_lines(&text, r.start(), r.end());
                (quiz::questions(here.as_deref().unwrap_or(Path::new("")), &text, Some(lines)), "selection".to_string())
            }
            QuizOp::All => {
                let mut v = Vec::new();
                let mut seen = std::collections::HashSet::new();
                for p in self.cards_all_paths().iter().filter(|p| is_note(p)) {
                    let abs = if p.is_relative() { self.root.join(p) } else { p.clone() };
                    if !seen.insert(abs.clone()) {
                        continue;
                    }
                    let t = if here.as_deref() == Some(abs.as_path()) {
                        text.clone()
                    } else {
                        match std::fs::metadata(&abs) {
                            Ok(m) if m.len() <= MAX_NOTE => std::fs::read_to_string(&abs).unwrap_or_default(),
                            _ => continue,
                        }
                    };
                    v.extend(quiz::questions(&abs, &t, None));
                }
                (v, "all notes".to_string())
            }
        };
        if qs.is_empty() {
            return self.notify("nothing to quiz: select a heading or list", false);
        }
        self.ex.quiz = Some(QuizUi { s: quiz::Session::new(qs, seed()), scope, result: false, sel: 0 });
    }

    fn quiz_open(&mut self, q: &quiz::Question) {
        if !q.path.as_os_str().is_empty() {
            if !q.path.is_file() {
                return self.notify("the note is gone", true);
            }
            self.open_path(&q.path);
        }
        self.goto_line_col(q.line, 0);
    }

    pub(super) fn quiz_key(&mut self, k: KeyEvent) {
        let Some(ui) = self.ex.quiz.as_mut() else { return };
        let plain = !k.modifiers.intersects(KeyModifiers::CONTROL | KeyModifiers::ALT);
        if ui.result {
            let n = ui.s.missed.len();
            match k.code {
                KeyCode::Up => ui.sel = ui.sel.saturating_sub(1),
                KeyCode::Down => ui.sel = (ui.sel + 1).min(n.saturating_sub(1)),
                KeyCode::Char('r') if plain && n > 0 => {
                    ui.s = quiz::Session::new(ui.s.missed.clone(), seed());
                    ui.result = false;
                    ui.sel = 0;
                }
                KeyCode::Char('s') if plain => {
                    let Some(q) = ui.s.missed.get(ui.sel).cloned() else { return };
                    self.ex.quiz = None;
                    self.quiz_open(&q);
                }
                KeyCode::Enter | KeyCode::Esc => self.ex.quiz = None,
                KeyCode::Char('q') if plain => self.ex.quiz = None,
                _ => {}
            }
            return;
        }
        match k.code {
            KeyCode::Esc | KeyCode::Char('q') if k.code == KeyCode::Esc || plain => {
                if ui.s.answered > 0 {
                    ui.result = true;
                    ui.sel = 0;
                } else {
                    self.ex.quiz = None;
                }
            }
            KeyCode::Char(' ') | KeyCode::Enter if !ui.s.revealed => ui.s.reveal(),
            KeyCode::Char(c @ ('y' | 'n')) if plain && ui.s.revealed => {
                ui.s.answer(c == 'y');
                ui.result = ui.s.finished();
                ui.sel = 0;
            }
            _ => {}
        }
    }

    pub(super) fn quiz_mouse(&mut self, m: MouseEvent) {
        if matches!(m.kind, MouseEventKind::Down(MouseButton::Left)) {
            if let Some(ui) = self.ex.quiz.as_mut() {
                if !ui.result && !ui.s.revealed {
                    ui.s.reveal();
                }
            }
        }
    }

    pub(super) fn draw_quiz(&mut self, w: usize, h: usize) {
        let Some(ui) = &self.ex.quiz else { return };
        if !ui.result {
            let Some(q) = ui.s.current() else { return };
            let title = format!(" Quiz {}  {}/{}  {}", ui.scope, (ui.s.answered + 1).min(ui.s.total), ui.s.total, q.path.file_name().map_or(String::new(), |n| n.to_string_lossy().into_owned()));
            let foot = if ui.s.revealed { "y got it   n missed   Esc end" } else { "Space show answer   Esc end" }.to_string();
            let (heading, segs, revealed) = (q.heading.clone(), q.segs.clone(), ui.s.revealed);
            return self.draw_card_panel(w, h, &title, heading.as_deref(), &segs, revealed, &foot);
        }
        let (n, sel) = (ui.s.missed.len(), ui.sel);
        let score = format!("{}/{}  {}%", ui.s.correct, ui.s.answered, ui.s.percent());
        let title = format!(" Quiz {}  result", ui.scope);
        let rows = h.saturating_sub(8).clamp(1, 12);
        let m = n.min(rows);
        let top = (sel + 1).saturating_sub(rows);
        let labels: Vec<String> = ui.s.missed.iter().skip(top).take(m).map(|q| format!("{:>4}  {}", q.line + 1, q.label())).collect();
        let bw = w.saturating_sub(4).clamp(20, 70).min(w);
        let bh = 4 + m;
        let (x0, y0) = ((w - bw) / 2, h.saturating_sub(bh) / 3);
        for y in 0..bh {
            self.screen.fill(x0, y0 + y, bw, PANEL);
        }
        self.screen.fill(x0, y0, bw, status());
        self.screen.text(x0, y0, &title, status(), bw);
        self.screen.text(x0 + 2, y0 + 1, &score, PANEL, bw.saturating_sub(4));
        self.screen.text(x0 + 2, y0 + 2, if n == 0 { "All correct." } else { "Missed:" }, PANEL, bw.saturating_sub(4));
        for (i, l) in labels.iter().enumerate() {
            let st = if top + i == sel { select() } else { PANEL };
            self.screen.fill(x0 + 1, y0 + 3 + i, bw.saturating_sub(2), st);
            self.screen.text(x0 + 2, y0 + 3 + i, l, st, bw.saturating_sub(4));
        }
        let foot = if n > 0 { "r re-quiz missed   s source   Up/Down   Enter close" } else { "Enter close" };
        self.screen.fill(x0, y0 + bh - 1, bw, status());
        self.screen.text(x0 + 1, y0 + bh - 1, foot, status(), bw.saturating_sub(2));
    }
}
